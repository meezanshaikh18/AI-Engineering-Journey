# 🚀 SQL & Microsoft Excel Fundamentals

This module introduces the fundamental concepts of **SQL** and **Microsoft Excel**, two essential tools for working with data. It focuses on understanding how data is stored, organized, queried, and managed while building a solid foundation for Data Analytics, Data Science, and AI Engineering.

---

# 📚 Learning Objectives

* Understand the basics of relational databases.
* Learn SQL syntax and database operations.
* Explore the Microsoft Excel environment.
* Build the foundational skills required for data analysis.
