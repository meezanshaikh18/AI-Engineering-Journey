# 🚀 SQL Fundamentals — Day 1

This module introduces the fundamentals of **Structured Query Language (SQL)** and relational databases. It focuses on understanding how data is organized, stored, retrieved, and managed using SQL, building a foundation for Data Analytics, Data Science, and AI Engineering.

---

## 📚 Learning Objectives

- Understand the fundamentals of relational databases.
- Learn basic SQL syntax and database operations.
- Understand databases, tables, rows, and columns.
- Practice creating, retrieving, updating, and deleting data.
- Learn how to work with `NULL` values.

---

- Introduction to SQL
- Relational Databases
- Databases
- Tables
- Rows and Columns
- Basic SQL Syntax
- Database Connections
- CRUD Operations
- `NULL` Values
