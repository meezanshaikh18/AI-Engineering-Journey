# Day 01 — SQL Fundamentals

## Overview
Started learning SQL using **Microsoft SQL Server Management Studio (SSMS)**, focusing on database management, Data Definition Language (DDL), and Data Manipulation Language (DML).

## Topics Covered

### 1. SQL Fundamentals
- Introduction to SQL and database management.
- Creating and working with databases and tables.

### 2. Data Definition Language (DDL)
Learned commands used to create, modify, and remove database structures.

- `CREATE` — Create databases and tables.
- `ALTER` — Modify existing database structures.
- `DROP` — Remove database objects.
- `TRUNCATE` — Remove all records from a table.

### 3. Data Manipulation Language (DML)
Learned commands used to manage table records.

- `INSERT` — Add new records.
- `SELECT` — Retrieve records.
- `UPDATE` — Modify existing records.
- `DELETE` — Remove records.

### 4. Practical Exercises
- Created databases and tables.
- Inserted and retrieved employee records.
- Updated and deleted records using `WHERE`.
- Practiced modifying table columns.
- Explored `DELETE TOP` for deleting a limited number of records.
