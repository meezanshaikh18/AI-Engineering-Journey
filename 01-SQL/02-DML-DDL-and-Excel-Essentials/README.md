# 🚀 SQL DML, DDL & Microsoft Excel Essentials

This module expands on the fundamentals of **SQL** and **Microsoft Excel** by introducing essential database manipulation and definition commands while exploring spreadsheet fundamentals and data formatting techniques.

The primary objective is to develop practical database management skills and strengthen the understanding of how structured data is stored, modified, and represented in real-world applications.

---

# 📚 Learning Objectives

* Understand Data Manipulation Language (DML) and Data Definition Language (DDL).
* Perform CRUD operations using SQL.
* Learn how to modify database structures.
* Explore spreadsheet fundamentals in Microsoft Excel.
* Understand different data types and number formatting.
