# 🚀 SQL Day 2 — DML & DDL Commands

This module focuses on **Data Manipulation Language (DML)** and **Data Definition Language (DDL)** in SQL. Through hands-on practice, I explored how to create and modify database structures and insert, retrieve, update, and delete records.

---

## 📚 Learning Objectives

- Understand Data Manipulation Language (DML).
- Understand Data Definition Language (DDL).
- Perform CRUD operations using SQL.
- Learn how to modify database structures.
- Practise managing database records with SQL queries.

---

## 🗄️ Topics Covered

### Data Manipulation Language (DML)

- `INSERT` — Insert records into a table.
- `SELECT` — Retrieve data from a table.
- `UPDATE` — Modify existing records.
- `DELETE` — Delete records from a table.

### Data Definition Language (DDL)

- `CREATE` — Create database objects.
- `ALTER` — Modify existing database structures.
- `DROP` — Remove database objects.
- `TRUNCATE` — Remove all records from a table.

### Additional Concepts

- DELETE command
- DELETE with conditions
- Database record management
- SQL query execution
