## 🗓️ Day 01 — SQL Fundamentals

**Topics Covered:**

- SQL fundamentals and database management.
- **DDL (Data Definition Language):** `CREATE`, `ALTER`, `DROP`, and `TRUNCATE`.
- **DML (Data Manipulation Language):** `INSERT`, `SELECT`, `UPDATE`, and `DELETE`.
- Creating databases and tables.
- Adding, modifying, and removing table columns.
- Retrieving, updating, and deleting records using `WHERE`.
- Practicing `DELETE TOP` and employee table operations.
